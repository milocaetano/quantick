This ledger does not claim that all 3,213 original lines migrated. Four policy tests move to the headless model, and `scene_row` (the header controls' scene rows, moved out of `app::control::scene`) gains `the_scene_rows_of_glyphs_samples_window_and_panel`. The retained file historically includes unrelated integration owners; later chrome and picker children retain their explicit obligations above. New same-frame reference coverage pins the header/chart cache boundary. Existing `chart::pane_header`/`chart::flow_band` domain rules and tests stay with their authoritative owner.
