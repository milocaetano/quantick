# Signed exceptions to the headless rule.
#
# CLAUDE.md, Architecture: "Everything below `app` is headless -- no UI, no
# network, no async, no wall clock." `crates/guards/src/headless.rs` enforces
# it over the production source of the crates that sentence names. A remaining
# site is legitimate only with a reason written here.
#
#   <workspace-relative path> <identifier> <reason>
#
# The identifier is spelled exactly as `FORBIDDEN` names it. Lines beginning
# with `#` are comments. An entry naming a site the scan no longer finds is
# itself a finding: an allowlist nobody prunes becomes a list of permissions
# granted to code that is gone, which the next author reads as precedent.
#
# There is no ratchet and no recorded count. Four entries is not a budget to
# spend; each one is an argument somebody has to make again to add a fifth.

crates/replay/src/scratch.rs SystemTime::now test-only helper; the nanoseconds seed a unique scratch directory name and never reach a result. The module ships in `src/` rather than under `tests/` only because a crate's own tests cannot see an integration test's items.
crates/control-local/src/scratch.rs SystemTime::now test-only helper; identical to `replay`'s, and separate because a crate that may not depend on another cannot share one.
crates/orderflow/src/engine.rs Instant::now a stopwatch around the projection build and the live pass, feeding `last_projection_ms` and `last_live_ms`. Both are diagnostic counters the health panel reads; neither reaches anything the projection returns, and `project_at` is told `now` by its caller, so the cache cadence stays deterministic.
