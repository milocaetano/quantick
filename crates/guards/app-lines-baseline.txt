# The app-lines ratchet's ceiling (`crates/guards/src/app_lines.rs`): the
# production lines of every tracked file under crates/app/, as the size guard
# counts them (top-level `#[cfg(test)]` items and `tests/` excluded). One
# `crates/app <ceiling>` entry and the `!budget` capping it; `#` starts a
# comment.
#
# An absolute count rather than `app`'s share of the workspace: a share falls
# whenever another crate grows, so it can improve while the trunk does not.
# This number may only fall. `cargo run -p quantick-guards -- --tighten`
# writes the lower number once it sits more than 200 below. A raise is this
# entry and the budget, both raised in the same change with a comment saying
# why.
#
# Recorded at main bcfb5f19 when the guard landed: 121,743 lines, the same
# number `--report` prints as `crate.lines.app`. Tightened to 103,598 after
# campaign #542 moved code out of `app` into eleven new crates.
#
# Raised by 89 lines for the analyst tier, all of it drawing and consent code
# in the surface that owns consent: a fifth section of scope checkboxes in the
# access panel, the status and button arms that name the tier, and the window
# scrolling that the taller body needed — on a 1009-point screen the enabled
# panel reached the bottom edge and left the disable button unreachable. The
# tier's own logic did not land here: the profile, its ceilings and the test
# for what belongs to it are in `control-host`, and the four scope sections
# now share one checkbox loop where a fifth copy would have gone.
# Raised by 328 lines for the hub split (`feat/slim-hub-modules`): the
# drawings, indicators, pane, theme, candle-view and crate-root hubs became
# facades over leaf modules, so a feature that names one type no longer reads
# the whole file. A split cannot pay for itself in lines — each leaf costs a
# module declaration, its own import preamble and a re-export line in the
# facade — and no line of logic was added: the three measured representatives
# read 72%, 51% and 41% fewer lines (PR body, `tools/read_cost/measure.py`).
# The lines bought read cost, which the size ratchet does not measure.
# Raised by 169 lines for the day separator (`feat/day-separator`): one new
# render package, `pane/render_registry/days.rs`, docked through the existing
# layer port, plus its call site and the time strip standing aside for the
# dates it writes. All of it is drawing and label placement; the rule for
# where a day starts is `quantick_civil::day_starts`, below `app`, with its
# tests.
# Raised by 1 line for opt-in FRVP labels: a serde rename so presets saved
# while labels defaulted on stop counting as the trader's choice.
# Raised by 264 lines for the quick bar switch (`surfaces/bar_switch.rs`):
# drawing and key reading only, docked as a new file on the `Surface` port.
# What the typed number means lives in `quantick-engine`
# (`BarRegistry::quick_candidates`), and the change applies through the same
# `set_pane_bar_spec` the control plane uses; there was no app code to move out.
# Raised by 24 lines for Renko bars (`feat/renko-bars`): the pane hands the
# indicators and the strategies every bar one print closes, the bricks a
# builder cut late from prints it held as history and never as a close; it
# puts the view and the marks back on their market time when older history
# re-cuts a Renko series, and shifts every other series by the bars added;
# and the chart read names the rule's inferred step and the prints it holds
# or found off it. The rule, the step it reads off its own prints and the
# query that reads `50R` live in `quantick-engine`.
