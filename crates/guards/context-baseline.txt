# The recorded ceiling, in bytes, for every context file over the threshold —
# the files a Claude session loads before it reads any code. One
# `path ceiling` pair per line; `#` starts a comment.
#
# These are costs, not targets. Every byte here is paid on every turn of every
# session that loads the file, so the only direction an entry should move is
# down. The `!budget` line caps their sum: raising one file means lowering
# another in the same change.
#
# Kept as data rather than a Rust `const` for the reason the size baseline is:
# a raise is then a data diff a reviewer can see, and `--tighten` can rewrite a
# line-oriented file safely.

# `references/` beside each skill, which a run reads only when it reaches that
# dimension. Each of these three is still the single largest thing a session
# loads when it invokes the skill, so each is debt, not a target.

# The sum of every ceiling above. Raising one means lowering another.
#
# Known sharp edge, stated rather than smoothed: this total sits exactly on
# the sum, and a file crossing the threshold enters at 10,000 bytes or more.
# So the next new entry costs a 10,000-byte cut somewhere else, and the likely
# answer is to raise this line instead. That is the escape hatch working as
# designed — one number, in one place, that a reviewer watches move — but it
# is a wider door here than in the size baseline, where the threshold is small
# against the total. Widening the gap on purpose would be the other choice,
# and it is the trader's: it trades teeth for the convenience of the branch
# that next crosses the line.
!budget 155007
