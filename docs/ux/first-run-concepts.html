Quantick · first run · UX proposal

Open the app, the chart is already running.

Eight designers proposed, a five-role panel debated and merged ideas, and five finalists remain, very different from each other. All of them avoid the tour: newcomers learn by using the real product. The mockups below are clickable and the charts run on simulated data.

8designers, each with one lens: card home screen, chart already open, Ctrl+K-style search, recipes, market map, live preview, newcomer and B3 trader.
5roles on the critique panel: visual designer, interaction designer, B3 day trader, crypto scalper and an engineer estimating egui cost.
5finalists, some merging several proposals. Panel order: 1 is the recommendation.
  • Visual designer: one beautiful full-screen chart beats seven flashing sparklines. Motion is saved for the chart.
  • Interaction: the fastest first run asks for no choice at all. A live chart behind the picker gives both.
  • Crypto scalper: open on vol:5 with bubbles, not a bare tick:50 candle chart. The bubbles are the product.
  • B3 trader: “mini índice” must find WIN, and outside the session it must say “Market closed · reopens Mon 09:00 BRT”. A dead tile looks like a broken app.
  • Engineer: seven live tiles are seven feed subscriptions at launch (cost L). A chip with a dropdown over one chart is cost S.
  • Everyone: every path becomes a named command (no mouse needed), and replay always shows as REPLAY, never as live.
