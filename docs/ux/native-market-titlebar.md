# Native market title strip

The existing market arrangement occupies a 52-logical-point first client row in one undecorated native window. The existing 28-logical-point menu row remains below it. This stage replaces OS decoration; it does not claim a net row-height saving before the separate menu consolidation. Market IDs, feeds, background work, picker and last-market close policy retain their existing owners.

The bounded strip keeps the selected market visible. Its all-markets menu reaches overflow markets, and the plus button remains beside the strip. Tab controls use stable market IDs. Free space between markets and window controls is the native drag target; widgets do not initiate dragging. Double-clicking free space maximizes or restores. Native minimize, maximize/restore and close controls use the ordinary viewport commands, including the existing shutdown path.

Window movement, edge resizing and Windows snapping remain native OS gestures under desktop authority. They are deliberately excluded from the application control API: this stage grants no arbitrary desktop positioning. `scene.controls` names the drag target and reports its current bounds for a desktop operator; bounds alone do not execute a gesture. `layout.window.state.set` requests normal, maximized or minimized presentation under cockpit layout authority with a required idempotency key. The accepted result is a request, not an OS acknowledgement; the scene's minimize/maximize selection reports the last viewport state observed by a frame. These requests run outside control replay. `app.exit` retains its authority exclusion, and closed is not a valid API state.

In a normal window, the outer four logical points accept native resizing in all eight edge and corner directions. Corner targets extend twelve logical points along each adjacent edge without covering widget interiors. These targets show resize cursors and hand the primary-button gesture to the OS through egui's `BeginResize` command. Maximized, minimized and fullscreen windows do not offer these resize targets.
